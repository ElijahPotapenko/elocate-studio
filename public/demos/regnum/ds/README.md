# Regnum DS

Своя дизайн-система кейса Regnum (по правилу `../../_shared/README.md`: кожа у каждого кейса своя, механика общая).

| Слой | Файл | Что внутри |
|---|---|---|
| Ручки + выводы | `tokens.css` | ~15 чисел (оттенки металла/акцента/фона, сила свечения, срез, шрифты) → все цвета, градиенты, свечения |
| Компоненты (вид) | `components.css` | только `var(--токены)`, ни одного «голого» цвета |
| Компоненты (React) | `components.js` | `Orn`, `Gem`, `Badge`, `Emblem`, `CrownWheel`, `VipCard`… — цвета не знают |
| Иконки | `icons.js` | game-icons.net (CC BY 3.0, атрибуция обязательна) + свои линейные |

**Лаба** — `../lab/index.html`: ручки, темы рядом, палитра, шрифты и все компоненты с кодом.
Подкрутки лабы хранятся в `localStorage['regnum-ds-look']`, демо открывается с ними (`?theme=royal` — сброс на пресет).

**Новая тема:** покрутил ручки в лабе → «Copy theme CSS» → вставил блок `[data-theme="…"]{…}` в `tokens.css`
и добавил строку в `THEMES` в `components.js`. Больше ничего трогать не нужно.

**Новый компонент:** нужен цвет — сначала вывод в `tokens.css` (из ручек), потом стиль в `components.css`,
потом история в лабе. Свечения — через `--glow-*` (одна ручка `--glow`), анимации — только `transform`/`opacity`.
