# Support bot demo

Мультиязычный бот поддержки для клиники (демо-компания и цены вымышленные). Показывает механику, которую можно перенести на любой бизнес:

- отвечает **только из базы знаний** (`bot/kb.py`), на языке клиента (PT, EN, PL, RU, UA и другие);
- собирает заявку на запись по шагам (имя, услуга, день и время, контакт), готовую заявку кладёт в очередь `data/leads.jsonl`;
- **передаёт человеку** (`data/handoffs.jsonl`) при острой боли и кровотечении, жалобах и возвратах, просьбе позвать человека, и когда ответа нет в базе;
- **код не верит модели слепо**: проверяет JSON, сверяет каждую сумму в евро с базой знаний (выдуманная цена = повтор, потом передача человеку), принудительно передаёт срочные случаи и жалобы, текст клиента не попадает в системные правила и не может стать флагом командной строки;
- модель без инструментов и без MCP (`claude -p --tools "" --strict-mcp-config`), то есть бот ничего не может делать, только отвечать текстом.

## Запуск
```bash
BOT_LLM=claude python3 server.py        # http://127.0.0.1:8765 (нужен вход в Claude Code)
BOT_LLM=ollama python3 server.py        # локальная модель qwen2.5:3b
python3 -m unittest discover -s tests -t .   # 22 теста, без сети
python3 scripts/record.py               # записать настоящие разговоры в transcripts/all.json
python3 scripts/export_static.py        # статичная версия dist/index.html (для сайта студии)
```

## Структура
`bot/engine.py` (логика и защиты) · `bot/llm.py` (Claude CLI, Ollama, Mock) · `bot/kb.py` (знания) · `server.py` (локальный сервер) · `ui/index.html` (чат + «что видит команда») · `tests/` · `transcripts/` (записи с реальной моделью)

Чтобы подключить WhatsApp Business, Telegram или сайт: движок (`Bot.reply(session, text)`) не зависит от канала, нужно только принимать сообщения вебхуком и отдавать ответ.
